# Character pictures

Drop a picture here to replace a character's drawn art. The file name is the character:

| File | Character |
| --- | --- |
| `ada.png` | Mama Ada |
| `tunde.png` | Tunde |
| `zara.png` | Zara |
| `blaze.png` | Blaze |
| `greta.png` | Prof. Greta |
| `mei.png` | Mei |
| `maddie.png` | Maddie |
| `priya.png` | Priya |

- PNG, WebP or JPG. Square works best (512 x 512 is plenty). It is shown in a circle.
- Add `<name>-talk.png`, the same picture with the mouth open, and the character lip-syncs while talking.
- Use art you made, commissioned, or generated with a tool whose licence lets you use it. Don't use screenshots of existing anime characters.
- Characters without a picture keep their drawn version.
